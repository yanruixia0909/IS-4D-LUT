## 1. 数据集与预处理

实验在 **LOLv1** 数据集上进行：训练集 485 对（`input/` 与 `target/` 同名配对），
测试集 15 对，图像分辨率为 400×600（少数为 600×400）。

- **训练**：对每对图像同步随机裁剪 **256×256** 的块，并以 **0.5** 的概率做水平翻转；
  不缩放、不做反射填充、不使用掩码，裁剪区域全部参与损失计算（256 为 2³ 的整数倍，
  前向无需补边）。
- **测试/推理**：保持原始分辨率。当输入边长不是 8 的倍数时，网络内部先用 `replicate`
  方式补齐到 8 的倍数，前向结束后裁回原尺寸（`is4dlut/models/is4dlut.py::_pad`），
  因此输出与输入严格同尺寸。

| 参数更新次数 | 1×10⁵ |

| 梯度裁剪 | 最大范数 1.0（生成网络与判别网络分别裁剪） |
| 随机种子 | 0（`--seed` 可改） |
| 权重保存 | 每 5000 次迭代保存一次，结束时另存 `is4dlut_last.pth` |
| 测试模型选择 | 未设验证集时固定使用第 1×10⁵ 次迭代的模型；设验证集时每 1000 次迭代在全分辨率验证图上计算 PSNR/SSIM |

## 3. LGM（4D LUT 生成模块）

- **编码器为四级二维结构**：stem 为 3×3 卷积（3→32）；随后三级下采样块，每级由
  stride-2 的 3×3 卷积接一个“两个 3×3 卷积 + 恒等支路”的残差细化块（ReLU）；
  四级通道数依次为 **32、64、128、256**。卷积层**不使用归一化**，激活为 ReLU
  （不是 InstanceNorm + LeakyReLU）。
- **强度图**：解码器以双线性上采样 + 3×3 卷积逐级回升并与同级特征相加，末端 3×3
  卷积输出单通道，经 Sigmoid 得 F_d ∈ (0,1)；查找先验 F_p = clip(I_L + F_d, 0, 1)。
- **融合系数**：最深层特征 → 全局平均池化（1×1，输出 256 维）→ 全连接 256→64 →
  ReLU → 全连接 64→M → Softmax；**该分支不使用 4×4 池化，也不含 dropout**。
- **4D LUT**：基表数量 **M=3**、每轴格点 **N=33**，参数形状 (3,3,33,33,33,33)
  （约 1.07×10⁷ 个参数，fp32 约 42.7 MB），按**恒等映射**初始化。
  融合表 L_4D = Σ_{m=1..M} ω_m ψ_m 逐点线性组合（fp32 计算）。
- **采样**：四个轴依次为 (r, g, b, d)，其中 d 取 F_p 的 BT.601 亮度
  （0.299, 0.587, 0.114）；坐标 clip 后映射到 [0, N−1]，取相邻 **16 个顶点**，
  按 d→b→g→r 的可分离顺序做**四线性插值**，得到 I_r。

## 4. 语义分支（SAEM / AFM / SFM）

- 金字塔与 LGM 同宽（**四级，32/64/128/256**）：图像编码器输入 I_r（3 通道），
  语义编码器输入 [I_r, I_L]（6 通道）。
- **SAEM**：通道维跨注意力（C×C 矩阵，缩放 1/√C，1×1 卷积投影，两个 LayerNorm2d），
  F_att = F_bc·LN(F_bc + F_bs) + LN(F_bc + F̃_bs)。
- **AFM**：对图像与语义各做一次自注意力，再做两个方向（图→语义、语义→图）的交叉
  注意力；6 个特征图拼接后经 3×3 卷积（6C→2C）→ 1×1 卷积（2C→C）→ Sigmoid 形成
  通道门控，输出 = Conv3×3((f_img+f_sem)·gate + f1c + f2c)。
- 解码端逐级双线性上采样并与同级特征相加；末端 3×3 卷积输出 3 通道残差 Δ，
  **I_o = clip(I_r + Δ, 0, 1)**。
- 同一层输出的语义特征 y 经 3×3 卷积 + 1×1 卷积得到 **K=3** 个语义区域 logits，供直方图损失使用。

> 说明：论文对语义分支的细节描述较少，本实现采用“内部编码器 + 通道注意力”的
> 形式给出语义特征，K=3 为可调超参数。

## 5. 损失函数

```
L_total1 = 1e-4·L_s + 10·L_m + 1.0·L_mse + 0.1·L_ssim
L_total2 = 1.0·L_recon + 0.1·L_sc + 0.1·L_sa
L_total  = L_total1 + L_total2
```

| 项 | 定义 |
|---|---|
| L_s | 融合后 4D LUT 沿四个轴相邻顶点的平均绝对差（4D 平滑正则） |
| L_m | BT.601 亮度沿强度轴的单调性惩罚：mean(relu(−(Y_{l+1}−Y_l)+1e−6)) |
| L_mse | I_r 与 GT 的均方误差 |
| L_ssim | 1 − SSIM(I_r, GT)，11×11 高斯窗（σ=1.5）、C₁=0.01²、C₂=0.03² |
| L_recon | Charbonnier(I_o, GT)，ε=1e−3 |
| L_sc | 语义引导直方图损失：在 1/4 分辨率的 3 个软语义区域上，对 RGB 各通道统计 **32 分箱**三角核软直方图（归一化为概率），以 **Wasserstein-1**（CDF 的 L1）度量，并叠加权重 **0.1** 的直方图均衡一致性项 |
| L_sa | hinge 形式 GAN 损失（见下） |

**判别器与对抗项**

- 结构：PatchGAN，Conv4×4/s2(32) → LeakyReLU(0.2) → Conv4×4/s2(64)+InstanceNorm → LReLU
  → Conv4×4/s2(128)+InstanceNorm → LReLU → Conv4×4/s1(1)，输出 patch 级 logits。
- 全局判别器作用于整幅 I_o；局部判别器作用于中心 **64×64** 裁剪。
- 语义权重 w ∈ [1,2]：由区域 softmax 的最大概率线性归一化后插值到 patch 网格。
  D 损失 = 0.5·E[(relu(1−D(real)) + relu(1+D(fake)))·w]，
  G 损失 = −E[D(fake)·w]。
- 两个判别器的参数由**同一个 Adam** 更新（β₁=0.9、β₂=0.999、ε=1e-8、lr=1e-4，
  与生成网络同学习率与调度）；增强网络与判别器按 **1:1** 交替更新。

## 6. 推理与效率测试

- 推理：批大小 1、**FP32**、保持原始分辨率；输入 [0,1] 归一化，输出 clip 到 [0,1]。
- 效率测试协议：统计完整增强流程（4D LUT 融合 + 四线性采样 + 语义分支 + 重建），
  **不包含图像读取与结果保存**；固定分辨率、批大小 1；预热 **50** 次后用
  **CUDA 事件**计时 **200** 次，报告**均值 ± 标准差**（另附中位数、P90、FPS、峰值显存）。
- 复现命令：`python tools/benchmark.py --ckpt checkpoints/lolv1/is4dlut_last.pth --size 400x600`

**实测结果（RTX 4060 Ti 16 GB，FP32，29.53 M 参数）**

| 分辨率 | 平均时延 | 标准差 | 中位数 | FPS | 峰值显存 |
|---|---|---|---|---|---|
| 256×256 | 15.09 ms | 0.49 ms | 15.00 ms | 66.3 | 622 MB |
| 400×600 | 65.04 ms | 0.41 ms | 65.03 ms | 15.4 | 1178 MB |
| 512×512 | 71.60 ms | 0.45 ms | 71.60 ms | 14.0 | 1246 MB |

训练吞吐（batch=1、256×256、含判别器与全部 7 项损失、FP32）约 **0.16 s/次迭代**，
故 1×10⁵ 次更新约需 **4.5 小时**（含稀疏验证会更长一些）。

## 7. 与常见转述写法的差异（按代码修正）

| 常见写法 | 本实现实际 | 说明 |
|---|---|---|
| 训练时缩放到 512×512，反射填充到 32 的倍数，填充区不计损失 | 随机裁剪 **256×256**，水平翻转；无缩放/填充/掩码 | 512 本身是 32 的倍数，二者互斥；且拉伸会改变 400×600 的纵横比与测试协议 |
| 单周期余弦退火 1e-4 → 1e-6 | 前 5×10⁴ 恒定，其后**线性**衰减至 0 | 代码中无 cosine scheduler |
| 随机种子 42 | 默认 **0**（`--seed` 可设为 42） | 若论文写 42，请用 `--seed 42` 重跑 |
| 五级编码器 8/16/32/64/128 | **四级 32/64/128/256** | 通道列表由 `base_channels=32, num_levels=3` 决定 |
| 3×3 卷积 + InstanceNorm + LeakyReLU(0.2) | **Conv + ReLU，无归一化** | InstanceNorm 在 fp16 下会溢出（判别器里已改 fp32 规避） |
| 4×4 自适应平均池化 → 1024 维，dropout 0.5 | **1×1 全局平均池化 → 256 维** → 256→64→M，**无 dropout** | 另注：128×4×4=2048≠1024，该写法本身不自洽 |
| RGB 各通道 256 分箱，σ=400 的 Sigmoid 差可微直方图 | **32 分箱三角核软直方图 + Wasserstein-1 + HE 一致性项** | 256 分箱在 512² 下显存/带宽开销显著 |
| 全局与局部判别器分别优化 | 两个判别器**共用一个 Adam**（参数合并） | 学习率与调度仍与生成网络一致 |
| 效率测试 50 预热 + 200 次 + mean/std | 已实现于 `tools/benchmark.py`（CUDA 事件计时） | 见第 6 节实测表 |

## 10. 可直接粘贴的段落版（连贯散文）

> 实验基于 PyTorch 2.0.0（CUDA 11.8，Python 3.10），在单张 NVIDIA RTX 4060 Ti（16 GB）
> 上完成，训练与推理均采用 FP32。数据集为 LOLv1：训练集 485 对、测试集 15 对，分辨率
> 400×600。训练时对每对图像同步随机裁剪 256×256 的块并以 0.5 的概率水平翻转，不做缩放、
> 反射填充或掩码；256 为 2³ 的整数倍，前向无需补边。测试保持原始分辨率，若边长不是 8 的
> 倍数，网络内部以 replicate 方式补齐再裁回，保证输出与输入同尺寸。优化器为 Adam
> （β₁=0.9、β₂=0.999、ε=10⁻⁸），权重衰减 0，批大小 1，共进行 10⁵ 次参数更新；初始学习率
> 10⁻⁴，前 5×10⁴ 次迭代保持恒定，其后线性衰减至 0；梯度裁剪最大范数为 1.0，随机种子为 0，
> 每 5000 次迭代保存一次权重，未设验证集时固定采用第 10⁵ 次迭代的模型进行测试。
> LGM 采用四级二维编码器，通道数依次为 32、64、128、256，下采样块由 stride-2 的 3×3 卷积
> 与两级 3×3 卷积构成的残差细化块（ReLU）组成，卷积层不含归一化；强度解码器经双线性上采样
> 逐级回升并与同级特征相加，末端 3×3 卷积加 Sigmoid 得到强度图 F_d，查找先验为
> F_p=clip(I_L+F_d,0,1)；融合系数由最深层特征经全局平均池化（256 维）、两层全连接
> （256→64→M）与 Softmax 预测，该分支不含 dropout。基础四维 LUT 数量 M=3、每轴格点 N=33，
> 参数张量形状为 3×3×33⁴（约 1.07×10⁷ 个参数，42.7 MB），按恒等映射初始化，融合表按
> L_4D=Σω_mψ_m 线性组合；采样轴依次为 (r,g,b,d)，其中 d 为 F_p 的 BT.601 亮度，坐标映射到
> [0,N−1] 后取相邻 16 个顶点，按 d→b→g→r 的可分离顺序做四线性插值得到 I_r。语义分支与
> LGM 同宽（四级 32/64/128/256）：图像编码器输入 I_r，语义编码器输入 [I_r,I_L]；每级先由
> SAEM 做通道维跨注意力（C×C，缩放 1/√C，两个 LayerNorm2d，F_att=F_bc·LN(F_bc+F_bs)+
> LN(F_bc+F̃_bs)），再由 AFM 对图像/语义各做自注意力并做双向交叉注意力，六图拼接后经
> 3×3 卷积（6C→2C）、1×1 卷积（2C→C）与 Sigmoid 形成通道门控，输出
> Conv3×3((f_img+f_sem)·gate+f1c+f2c)；解码端逐级上采样并与同级特征相加，末端输出 3 通道
> 残差 Δ，最终 I_o=clip(I_r+Δ,0,1)，最终层的语义特征 y 另经 3×3 卷积与 1×1 卷积给出 K=3 个
> 语义区域 logits。总损失为 L_total1=10⁻⁴L_s+10L_m+L_mse+0.1L_ssim 与
> L_total2=L_recon+0.1L_sc+0.1L_sa 之和：L_s 为融合 4D LUT 沿四轴的平均绝对差，L_m 为亮度
> 沿强度轴的单调性惩罚 mean(relu(−ΔY+10⁻⁶))，L_mse、L_ssim（11×11 高斯窗，σ=1.5）作用于
> I_r，L_recon 为 I_o 的 Charbonnier 损失（ε=10⁻³）；L_sc 在 1/4 分辨率的 3 个软语义区域上
> 对 RGB 各通道统计 32 分箱三角核软直方图，以 Wasserstein-1 距离度量并叠加权重 0.1 的直方图
> 均衡一致性项；L_sa 为 hinge 对抗损失，全局判别器作用于整幅 I_o，局部判别器作用于中心
> 64×64 裁剪，判别目标按语义权重 w∈[1,2] 加权，两个判别器共享同一 Adam 并与生成网络同学习率
> 调度，增强网络与判别器按 1∶1 交替更新。推理为批大小 1 的 FP32 模式，保持原始分辨率；
> 效率测试统计完整增强流程（4D LUT 融合、四线性采样、语义分支与重建），不计图像读取与结果
> 保存，固定分辨率下预热 50 次后用 CUDA 事件计时 200 次并报告均值与标准差。在该设置下模型
> 含 29.53 M 参数，实测 256×256 为 15.09±0.49 ms、400×600 为 65.04±0.41 ms、
> 512×512 为 71.60±0.45 ms（峰值显存分别为 0.62/1.18/1.25 GB），训练吞吐约 0.16 s/迭代，
> 10⁵ 次更新约需 4.5 小时。
